# Home work 10_1
Этот проект содержит набор инструментов для маскировки номеров банковских карт и счетов клиенто, филтрации транзакций.
## Функциональность
В модуле src/masks.py реализованы две основные функции:
1. **Маскировка счета (`get_mask_account`):**
   * Принимает номер счета
   * Маскирует номер счета, оставляя последние 4 цифры
   * Логирует выполнение функции в файл по пути (`'logs/masks.log'`)
2. **Маскировка номера карты (`get_mask_card_number`):**
   * Принимает название и номер банковской карты
   * Возвращает замаскированный номер банковской карты
   * Логирует выполнение функции в файл по пути (`'logs/masks.log'`)
В модуле src/processing.py реализованы:
1. **Фильтрация по статусу (`filter_by_state(list_dict: list, state: str = "EXECUTED")`):**
   * Принимает список словарей и дефолтное значение статуса
   * Возвращает новый список словарей, у которых значние 'state' соответствует заданному параметру 'state'
   * По умолчанию ищет операции со статусом 'EXECUTED'
2. ** Сортировка по дате (`sort_by_date(list_dict: list, reverse=True)`):**
   * Принимает список словарей и флаг порядка сортировки
   * Сортирует данные по ключу 'date'
   * Поддерживает сортировку как по убыванию (от новых к старым), так и по возрастанию
В модуле src/widget.py реализованы:
1.**Функция, определяющая, что именно введено: счет или номер карты (`ask_account_card(account_card: str)`):**
   * Принимает параметр, в котором находится либо номер карты, либо номер счета
   * Маскирует их по принципу, описанному в (`get_mask_card_number`) и (`get_mask_account`)
2. **Функция(`get_date(date: str)`), принимащая на вход дату и приводящяя ее в определенную форму**
   *Принимает на вход дату
   * Формирует из нее дату формата 'ДД.ММ.ГГГГ'
В модуле src/generators.py реализованы:
1. Функция генератор (`filter_by_currency`) которая принимает список словарей и маркер валюты. Отфильтровывает
операции в соответствии с введенной валютой и выводит их по очереди
2. Функция генератор (`transaction_descriptions`) которая принимает на вход список словарей и выводит какая именно
операция была в каждом словаре
3. Функция генератор (`card_number_generator`) которая принимает два числа (начальное и конечное) и генерирует 
номера карт, в диапазоне заданных чисел
В модуле src/decorators.py реализованы:
   1. Функция декоратор (`log`), которая логгирует данные либо в отдельный файл, либо если файл не указан выдает лог
консоль.
В модуле src/utils.py реализованы:
      1. Функция (` transactions_list`) которая принимает путь до файла .json с информацией о транзакциях и
трансформирует в список Python, а так же настроено логирование выполнения функции, записывающее логи в файл по пути (`logs/utils.log`)
В модуле src/external_api.py реализованы:
      1. Функция (`convertation_currency`) которая принимает на вход транзакцию и с помощью запроса на сайт
по url, получает курсы валют и конвертирует сумму транзакции в рубли
В модуле src/read_file.py реализованы:
      1. Функция (`read_file_csv`) которая на вход принимает путь до файла csv, читает его 
и на вывод отдает список словарей с транзакциями из файла
      2. Функция (`read_file_excel`) которая на вход принимает путь до файла xlsx, читатет его 
и на вывод отдает список словарей с транзакциями из файла
В модуле src/filter_bank_operations реализованы:
      1. Функция (`process_bank_search`) которая принимает на вход список с банковскими операциями
и строку поиска, выводит отфильтрованный список с операциями, в описании которых есть строка поиска
      2. Функция (`process_bank_operations`) которая принимает на вход список с банковскими операциями 
и список категорий операций, выводит отфильтрованный список опреаций, в которых есть опреации, соответствующие
списку поиска
В модуле Home_work реализованы:
      1. Функция (`main`) в которой реализована основная логика проекта, вопросы пользователю и вызов
всех функций для фильтрации списка транзакций по запросу пользователя
